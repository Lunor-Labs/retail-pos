# Staff Commission PDF Report Design

**Date:** 2026-06-05

## Summary

Add a per-staff monthly commission report that opens as a print popup and can be saved as PDF. Triggered by a download icon button on each row in the Commission tab of the Sales Staff page.

## Placement

Inside `CommissionReport` in `src/components/SalesStaff.tsx`, in the Actions column of each staff row — next to the existing Pay and expand (chevron) buttons. Only visible to admins.

## Trigger

A small download icon button (`FileDown` from lucide-react) on each commission row. Clicking it calls a `printCommissionReport(row, month, storeName)` function that opens a popup and auto-prints.

## Report Content (HTML popup)

A self-contained HTML page, no external dependencies. Structured as:

### Header
- Store name (passed in or read from settings)
- Title: "Commission Report"
- Staff name + role
- Month (e.g. "June 2026")
- Generated date

### Summary block (key-value pairs)
- Commission Rate
- Daily Target
- Total Revenue (month)
- Qualifying Days (e.g. "8 / 30 days")
- Commission Base (revenue on qualifying days)
- Commission Amount
- Payment Status (Paid / Pending)

### Day-by-day table
Columns: Date | Revenue | Target | Hit? | Commission
One row per day (same data as the expanded row in the UI). Qualifying days highlighted.
Total row at the bottom.

### Footer
- Small "Generated by [store name] POS" line

## Implementation

**New file:** `src/components/staff/commissionReportHTML.ts`
- Exports `buildCommissionReportHTML(row: CommissionRow, month: string, storeName: string): string`
- Self-contained HTML string with inline CSS (A4 page, clean table layout, print-ready)
- Inline JS: auto-calls `window.print()` then `window.close()` on afterprint

**Modified file:** `src/components/SalesStaff.tsx`
- Import `buildCommissionReportHTML`
- Add `printCommissionReportForRow(row)` function inside `CommissionReport` that builds the HTML and opens `window.open()`
- Add `FileDown` icon button to the Actions cell of each staff row (admin only)

## Data available (CommissionRow)
All data needed is already computed in `CommissionRow`:
```ts
member: StaffMember        // name, role, email
effectiveRate: number      // commission rate for the month
effectiveTarget: number    // daily target for the month
days: DayData[]            // per-day revenue, hit, commission
totalRevenue: number
qualifyingDays: number
commissionBase: number
commissionAmount: number
isPaid: boolean
```

## Out of Scope
- Email/share the PDF
- Download without print dialog (no jsPDF dependency)
- Bulk PDF for all staff
